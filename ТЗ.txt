ТЗ (MVP): Конвертер КТП (DOCX/ODT) → Excel для импорта в Дневник.ру
Цель
Получать из КТП (таблица в DOCX/ODT) 4 или 2 Excel-файла (по четвертям/полугодиям) в форматах XLS и XLSX, содержащих только 2 столбца:
    • Тема урока
    • Домашнее задание
С поддержкой отмен уроков: отменённые строки остаются пустыми, а темы/ДЗ “сжимаются” вниз без увеличения общего числа уроков.

1) Входные данные
1.1 Поддерживаемые форматы
    • DOCX
    • ODT
1.2 Требования к содержимому входного файла
    • Документ содержит хотя бы одну таблицу.
    • В таблице есть столбцы с темой и домашним заданием (в любых названиях/позициях).

2) Выходные данные
2.1 Форматы
Для каждой части (четверть/полугодие) формируются два файла:
    • XLS (Microsoft Excel 97–2003)
    • XLSX (Microsoft Excel 2007–2014)
2.2 Содержание файлов
Один лист, две колонки (строго в таком порядке и с такими заголовками):
    1. Тема урока
    2. Домашнее задание
(Другие поля не выгружаются.)
2.3 Имена файлов
Допустимы простые имена:
    • Ч1.xls, Ч1.xlsx, Ч2.xls… или П1.xls, П1.xlsx…

3) Основной сценарий (UX “для бабушек”)
Приложение работает как мастер из шагов. На каждом шаге одна основная кнопка: Далее.
Шаг 1. Загрузить файл
    • Зона drag&drop + кнопка “Выбрать файл”.
    • После загрузки приложение показывает найденные таблицы:
        ◦ “Таблица 1 (N строк, M столбцов)”
    • Если таблица одна — выбирается автоматически.
Шаг 2. Выбрать столбцы “Тема” и “ДЗ”
    • Предпросмотр таблицы (10–15 строк).
    • Пользователь выбирает столбцы кликом по заголовку/ячейке столбца:
        ◦ “Выберите столбец Тема”
        ◦ “Выберите столбец ДЗ”
    • Опция: “Первая строка — заголовки” (галочка).
    • Разделитель при объединении записей: перенос строки (по умолчанию).
Шаг 3. Разделить на части
    • Переключатель: 4 четверти / 2 полугодия.
    • Ввод количества уроков в каждой части.
    • Приложение показывает:
        ◦ “Всего строк уроков в КТП: X”
        ◦ “Сумма по частям: Y”
    • Кнопка “Далее” активна только если X == Y.
Шаг 4. Редактор частей
Вкладки: Ч1–Ч4 или П1–П2.
В каждой вкладке таблица:
    • № (автоколонка внутри приложения, в экспорт не идёт)
    • Тема урока
    • Домашнее задание
    • Статус (иконка/метка)
Поддержка:
    • Двойной клик по ячейке → редактирование
    • Ctrl+C / Ctrl+V для диапазона

4) Отмены и “сжатие программы”
4.1 Статус “Отменён”
Действие Отменить урок:
    • выбранная строка помечается красной меткой “ОТМЕНЁН”
    • Тема урока и ДЗ в этой строке становятся пустыми
    • строка остаётся на месте (как “дыра”)
Действие Вернуть урок:
    • снимает статус “ОТМЕНЁН”
    • (если строка пустая — остаётся пустой, пользователь может заполнить вручную или авто-сжатием)
4.2 Автокнопка “Сжать программу”
Назначение: темы и ДЗ с отменённых уроков переносятся вниз, чтобы программа “успела” без увеличения числа уроков.
Алгоритм внутри одной части (четверти/полугодия):
    • идём сверху вниз по строкам части
    • если строка “ОТМЕНЁН” → её содержимое считается “долгом” и переносится дальше
    • при встрече нормальной строки:
        ◦ к её теме и ДЗ добавляются все накопленные долги (через перенос строки)
        ◦ долги обнуляются
    • долги не переносятся за пределы части (если отменили в четверти — всё должно уложиться в этой четверти)
Если в конце части остался “долг” (не хватило проведённых уроков для сжатия):
    • приложение показывает предупреждение: “В конце Ч2 осталось N тем, которые некуда разместить внутри четверти.”
4.3 Drag&Drop (ручная коррекция)
    • Карточку (строку с темой/ДЗ) можно перетащить только вниз.
    • Если бросили на непустую строку:
        ◦ данные объединяются в ячейках (перенос строки)
    • Источник становится пустым (или помечается как отменён, если это была отмена) — правило надо закрепить:
        ◦ по умолчанию: источник становится “ОТМЕНЁН”, если пользователь выполняет действие “Отменить урок”
        ◦ если это просто drag&drop без отмены — источник становится пустым без красной метки
(Это уже мелкая реализация, но важно в ТЗ не смешать “перенёс” и “отменил”.)

5) Шаблоны для ДЗ (быстрый ввод)
Кнопки:
    • Конспект
    • Карточка
    • §…
    • Упр…
Поведение:
    • при нажатии вставляется шаблон в поле ДЗ выделенных строк
    • для §… и Упр… вставляется § / Упр и курсор остаётся после пробела (пользователь дописывает)

6) Экспорт
Кнопка “Экспорт”:
    • генерирует для каждой части два файла: .xls и .xlsx
    • показывает “Готово” + кнопку “Открыть папку”
